# Spotify Data Analysis Using Python

## 📌 Project Overview
This project focuses on analyzing Spotify music data using Python and Pandas. The objective is to perform data transformation, handle missing values using mean imputation, generate meaningful insights, and visualize the findings.

## 🎯 Objectives
- Read and understand a CSV dataset.
- Explore the dataset using Pandas.
- Perform data cleaning and transformation.
- Identify and handle missing values.
- Apply mean imputation to numerical columns.
- Generate meaningful insights.
- Visualize the findings using charts.

## 📂 Dataset
- **Dataset Name:** Spotify Tracks Dataset
- **Source:** Kaggle
- **Format:** CSV

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Visual Studio Code

## 📊 Tasks Performed
1. Dataset selection and reading.
2. Data understanding and exploration.
3. Data transformation.
4. Null value identification and handling.
5. Mean imputation.
6. Insight generation.
7. Data visualization.

## 📈 Visualizations
- Top 10 Popular Songs
- Danceability Distribution
- Energy vs Danceability

## 🎓 Learning Outcomes
- Understanding CSV datasets.
- Working with Pandas.
- Performing data preprocessing.
- Handling missing values.
- Generating insights from data.
- Creating visualizations.

## 📝 Conclusion
This project demonstrates the use of Python and its data analysis libraries to explore, transform, clean, analyze, and visualize Spotify music data.
